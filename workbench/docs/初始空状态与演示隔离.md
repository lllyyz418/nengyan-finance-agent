# 初始空状态与演示隔离

首次打开或刷新网页默认进入“等待分析”，不会自动载入样例，也不自动恢复某个历史财务任务。

- 六个指标保留中文名称与公式，数值为“—”，无同比和趋势数据。
- 文件状态等待分析，解析覆盖、可用性和质量计数显示“—”，不展示样例文件指纹或审计口径。
- 风险和趋势区域展示等待提示，不生成“正常”“已触发”等结论或曲线。
- 指标明细为空，Excel/PDF导出禁用，不能打开示例证据。
- 同行选择保留配置，但未计算的结果显示“—”，预选公司不意味着已有财报数据。
- 日志任务需手动选择，创建新任务后自动定位新任务；日志与总览独立。

“查看演示”为显式操作。演示只读取前端模拟样例，不创建或保存真实分析任务。页面与示例证据抽屉标注模拟性质；导出继续携带演示标记。退出后恢复等待状态，或返回之前载入的真实结果。

真实分析成功或在历史记录打开财务任务后，进入“真实结果”。演示切换不覆盖保存的真实结果、报告、证据ID及历史趋势。新的真实任务开始时先清空结果展示；失败时保持空状态，不退回模拟值。

页面右上角提供“返回工作台”。点击后关闭历史列表和证据抽屉，回到分析总览顶部，恢复等待分析并清空所选日志；不删除后端报告、文件或历史记录。历史列表原有的返回按钮使用相同行为，避免退回后仍停留在旧报告。正在执行在线分析时暂时禁用返回按钮，防止任务结果晚到后覆盖新的工作台视图。

公告和扫描件仍是独立上传区域，不以其识别结果冒充财务总览结果。既有历史任务及后端文件不作删除或迁移。

验证：`node scripts/test-analysis-state.mjs`；`node node_modules/typescript/bin/tsc -b`。本次仅修改前端，不需要重启后端。

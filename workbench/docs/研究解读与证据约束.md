# 研究解读（第一阶段）

## 用户操作

- 分析报告默认进入“研究解读”；“财务摘要”保留原有摘要及旧报告入口。
- 新财报完成财务计算并保存后，已配置 DeepSeek 时自动提交一次本期研究任务。财务结果不等待文字生成。
- 旧历史结果不需要重新上传。打开结果后，点击“生成研究解读”。
- 补齐历史或完成人工选择的同行比较后，点击“根据新数据更新”。新解读另存版本，旧版本仍可选择。
- 刷新和读取版本不会触发模型；数据签名及提示词版本相同的已完成任务会复用，避免重复调用。
- 可复制解读或导出 PDF；原文按钮使用该项数据实际所属任务的证据。

## 内容组织与边界

每条观点包含服务器核对的观察、模型经营解释、数据及原文依据、其他可能解释、后续核查和判断边界。章节按数据选择核心判断、增长与盈利、现金流、资金投入、历史、所选同行、核查重点，不强行凑满。

第一阶段仅利用已经保存的有效财务指标、原始事实、同报告比较值、实际规则条件、已经取得的历史和所选同行。不重新计算指标，不把产品结构、客户、价格、产能或管理层解释编成已知事实。这些内容最多作为待验证假设或问题。完整经营原文的定向提取属于后续阶段。

未提取不等于未披露。数据缺失不能记零，未触发不能解释为安全，规则触发不能解释为已证实风险。历史及同行要求相同报告类型、期间、单位及计算口径；所选同行不代表行业平均或全行业排名。

## 输出校验

- 输入限定为有已保存原文证据且非冲突的有限数值；引用保留任务、事实、页码。
- 事实观察和标题由服务器构建；模型的观察编号必须存在，引用集合必须准确匹配所选观察，不能挪用其他指标解释规则。
- 同报告比较期直接读取已经保存的比较值，不用本期值冒充上期，不在研究层新算变动率。
- 模型数值使用占位符，由服务器填入数值与单位。阻止未知引用、裸数值、外链/执行标记、越范围比较及部分确定性误导措辞。
- JSON 输出不等于正确。先做结构及内容约束校验；最多一次带校验反馈的修正。个别不合格观点被排除并说明，核心判断或整体不合格时失败，不展示未经核对文字。
- 这些检查不能证明所有经营解释或因果推断都正确，页面明确保留人工复核边界。不输出目标价、交易评级或无依据预测。

## 独立任务与保存

`backend/data/research_reports/<原财务任务 ID>/` 保存版本、冻结输入、模型名、提示词版本、数据签名与时间；不写回原财务报告，不混入普通历史任务计数。API 密钥来自现有环境配置，不写入研究文件。

模型线程池最多同时运行 2 项，总排队容量 6 项；每次请求超时 120 秒，不做网络自动重试。结构修正最多再调用一次，因此不能承诺固定生成时间或固定调用成本。

停止生成后不发布迟到结果。已发到模型服务的请求不保证可撤销或免计费。后端重启前的未完成研究任务显示已中断，不偷偷重新调用模型。财务摘要、已完成版本与历史记录仍保留。

现有 `DEEPSEEK_API_KEY`、`DEEPSEEK_MODEL` 配置继续使用；`FINANCE_RESEARCH_AUTOGENERATE=0` 可关闭新财报的自动研究生成，手动入口不变。配置修改后重启后端。

## 验收入口

离线回归：`scripts/run-upload-regression.py test_research_reports` 与现有完整回归集合。前端：`scripts/test-research-reports.mjs`，包含视图、证据、取消、版本隔离和读取不触发生成。

`scripts/check-research-report.py` 是需显式运行、会消耗模型额度的真实验收，不属于离线测试。仅使用指定的已保存公开报告，所有新任务、输入与模型尝试保存在 `artifacts/research-reports/acceptance-*`；原生产任务不被修改。

`scripts/serve-research-qa.py <验收目录>` 提供隔离的 5190 端口页面，禁止模型调用，仅供验收，不替代用户的 5173/8001 服务。

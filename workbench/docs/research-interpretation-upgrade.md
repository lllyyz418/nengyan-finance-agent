# 研究解读升级与验收（2026-10-17）

## 本次范围

只升级独立的研究解读版本和阅读体验，不覆盖财务引擎结果、旧版财务摘要、历史任务或原始 PDF；没有重启或删除用户的服务。

## 从用户模板学习的方法

5 个输入文件实际为 4 份不同报告，其中两份 H3_AP202408061639151491 文件内容哈希一致。已在本地提取并阅读相关完整页面，渲染检查封面、目录及正文。

- 行业年度/季度综述：先提出研究主线，再连接盈利、现金、营运资金和投入；不以单个指标替代经营解释。
- 公司业绩点评：区分已实现业绩、驱动假设和后续验证，不只重述报表。
- 公司深度研究：业务基础、成本与竞争、会计口径、资金投入之间形成连贯关系。
- CFA Vestas 报告：关键判断要有支持条件、反向条件和取证路径。

仅借鉴研究组织方法，不复用其原文、企业数据、行业排名、预测、目标价、评级或估值假设。模板全文未发送给模型；它们不作为用户分析企业的事实证据。

## 内容与证据

- 写作规则版本：`evidence-research-7-analyst`。支持核心判断、业务、盈利、现金、资金投入、历史、所选同行、经营计划与风险、核查重点，按有据材料选章，不强制凑满目录。
- 新报告优先输出连贯判断、支持/削弱判断的后续信号、其他解释和具体核查事项。
- 另增 `issuer-prose-4` 经营原文提取，在独立 PDF 子进程中最多扫描前 80 页；识别管理层讨论的后续章节边界时提前停止。最多每类 2 段、合计 9,000 字，不执行 OCR。
- 从业务说明、现金原因、投入、计划与风险中挑选可定位段落。数字表格、承诺事项和明显注入式指令不进入该文字提取结果。
- 管理层解释属于公司披露，计划不等于已实现结果，风险披露不等于已发生损失；未提取不等于公司未披露。
- 经营节选独立冻结在研究输入中，保留文件哈希、文档 ID 和物理页。原文入口再次验证文件哈希；同一研究根任务之外、未完成版本或文件变更不能被当作有效原文打开。
- 模型引用由服务器所选 observation 绑定；未知编号、越过所选观察使用的数值、期间与公司口径冲突仍会被拦截。未通过校验的观点不展示，过少的有效章节需重新生成。
- 原文提取失败时退回有据的财务解读，并清楚说明本次材料限制，不把财务任务变成失败。
- 没有新增实时行业、市场价格、新闻、订单、盈利预测或估值数据。文字及因果解释仍需人工复核，不能把基本引用校验称为全面事实核查。

Windows 验收发现将 PDF 缓存嵌入多层版本目录会出现文件不可用错误，已改用现有的 operation/hash 隔离 PDF 缓存，避免额外的深层路径。

## 阅读与导出

- 桌面框高 800px，窄屏 720px；正文内部滚动，目录、复制和导出在滚动正文外侧。
- 数据、原文、其他解释和核查路径默认折叠，正文突出判断与跟踪信号。
- 窄屏隐藏研究目录侧栏，避免共享财务摘要样式的 display:flex 覆盖。
- PDF 导出读取完整 DOM 内容，包含未展开依据和滚动框外的末尾内容；不按截图或可视高度截断。
- 复制输入仍是完整已保存 Markdown，新增成功反馈和失败提示。内置浏览器的写入成功反馈已验证；其独立剪贴板桥接读取为空，未据此声称验证了操作系统剪贴板内容。

## 使用方式

重启后端并强制刷新工作台。新任务使用升级后的规则；旧任务打开后点击“更新研究解读”生成新版本。刷新本身不自动调用模型，也不会覆盖旧版内容。

本次未自动重启用户后端；只读 QA 服务器与正式目录隔离，验收结束关闭。

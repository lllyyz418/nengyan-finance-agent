# 会计政策与估计披露复核

本次只扩展年度报告中的研发资本化、固定资产折旧复核，保留前四条组合规则和原页面风格。

## 研发资本化

读取本年、上年研发总投入和当期资本化研发投入，统一为人民币元。分母必须为正，资本化金额不得为负或大于总投入。空白、横线、不适用及不可靠表列不会按零处理；显式零可参与计算。费用化金额与开发支出余额均不替代所需输入。

两期金额齐全且通过校验后，展示资本化比例及百分点变化。比例上升仅表示方向变化，显示“发现变化，需复核”，不直接标红为违规或财务风险，不设置未经验证的行业通用预警阈值。

## 折旧参数和变更披露

按相同资产类别比较折旧方法、使用年限、残值率和年折旧率；没有上期表时说明需要历史补齐，不用另一个公司的表。常规复核条款不当作实际变更，未找到变更段落也不当作没有变更。不同分类、多个版本及变更说明矛盾时保留不确定性。

报告明确勾选“重要会计估计变更不适用”且本期表可靠时，可完成本期披露层面的复核，但会说明尚未独立核对上期参数。这不是“已确认所有资产均未变化”。

## 状态与证据

- 已完成复核：在列明的有限范围内完成核对。
- 发现变化，需复核：存在比例上升、参数不同或实际变更披露，不等于违规。
- 数据不足：列出具体年度、字段及未取得原因。
- 需人工确认：已找到原表但未可靠读取，或披露/版本之间存在矛盾。可打开原文核实，当前不提供无证据的一键改判。

研发金额链接、折旧表链接和变更说明链接分别进入现有证据抽屉，支持打开对应 PDF 页码。文字披露不混进数值事实或金额计算。财务分析摘要使用同一组复核结果与中文原因。

## 使用方式

重启后端并刷新前端后，重新上传或检索报告。旧结果保持原样，不在浏览历史时重算。历史回溯取得上期年报后，新保存版本可以补充两期折旧比较；原任务和原报告正文保留。无需清空财报库、历史记录或删除 PDF。

解析覆盖有限，扫描页、复杂表格、非标准表头及仅在叙述中披露的金额仍可能需要人工核对；不会承诺所有公司的所有披露都能自动读出。

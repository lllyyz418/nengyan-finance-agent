# 导航前三项精简方案（已确认并实施）

当前“分析总览”是公司与任务操作区，“文件解析”主要显示文件身份及解析覆盖，“Agent 分析报告”显示完整文字报告。前两项相邻且都是分析前后状态，单独占导航容易显得重复。

建议将前三项精简为两项：

1. **分析总览**：保留公司选择、报告期、上传与公开报告搜索；将文件类型、公司/年度校验、解析覆盖与警告放在总览内的一张“文件与解析状态”卡。卡片默认简洁，可展开查看校验、文件指纹等细节。
2. **分析报告**：保留完整的中文分析报告和报告下载入口，将菜单名称从“Agent 分析报告”简化为“分析报告”。可在正文副标题解释报告由 Agent 生成，无需每个菜单重复标注 Agent。

只删除“文件解析”的独立导航入口，不删除其结果和证据；总览和报告分别有唯一锚点，滚动高亮仍按正文顺序变化。其余核心指标、风险复核、趋势、指标表、同行等入口不受影响。

理由：总览回答“分析的是谁、哪些文件、处理是否可靠”，报告回答“得出了什么结论”，指标与证据区负责核验。这样更接近实际研究工作流程。

已按确认方案实施：导航前两项为“分析总览”“分析报告”，文件与解析状态卡已放入总览，默认收起详情，展开后可查看当前结果的公司、年度与类型、报表口径、解析版本和文件指纹。总览与报告使用独立唯一锚点，滚动高亮按正文顺序变化。

演示状态单独标注，不将展示出的公司和年度称为已通过身份校验；真实信息仍需结合原文核验。本次仅调整前端，不修改已有报告、任务数据或后端接口。

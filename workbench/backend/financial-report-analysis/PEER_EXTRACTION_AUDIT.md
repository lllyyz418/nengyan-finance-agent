# 两家同行年报字段提取核查（v0.15）

本次核对的是缓存中的完整文本型 2025 年报：`300014_2025_1225045391.pdf`（亿纬锂能）和 `002074_2025_1225254220.pdf`（国轩高科）。以下均为财报披露的**人民币元**；JSON 的 `sources` 保留 PDF 哈希、实际页码、表格或行坐标。缓存 PDF 不随 Skill ZIP 分发。

## 亿纬锂能：第 9 页季度现金流

季度表把“经营活动产生的现金流量净额”的首字“经”分在相邻单元格。旧适配器只取第一个含汉字的单元格，因而无法识别该行。v0.15 在金额单元格之前受控拼接这种单字标签，保留表格行坐标及原值。

| 单季 | 经营活动现金流量净额（元） |
| --- | ---: |
| 第一季度 | 892,143,948.57 |
| 第二季度 | 1,480,421,763.04 |
| 第三季度 | 2,531,259,756.21 |
| 第四季度 | 2,588,306,198.97 |
| 四季合计 | **7,492,131,666.79** |

四季合计等于第 9 页披露的全年经营活动现金流量净额。四季均为正，`cash_collection_pressure` 现在有完整输入并返回 `not_triggered`。该状态只说明此联合筛查条件未全部满足。

## 国轩高科：第 193 页存货分类

原页是两层表头、六个金额列。`extract_text_lines()` 将“合计”行错列拆开，而 PDF 表格网格仍保留完整单元格。v0.15 只在**合并报表附注的“存货”项目、存货分类标题与下一小节之间**启用表格回退；须确认“期末余额／期初余额”列序、六列标题、类别行与合计行，且每期都满足“账面余额－跌价准备＝账面价值”。表格总额还须与类别金额逐列勾稽；不满足则保留 `insufficient_data` 和警告。

| 期间 | 存货账面余额（元） | 跌价准备（元） | 存货账面价值（元） |
| --- | ---: | ---: | ---: |
| 2025 年末 | 10,009,428,123.54 | 319,270,917.53 | 9,690,157,206.01 |
| 2024 年末比较列 | 7,490,059,485.35 | 368,758,486.87 | 7,121,300,998.48 |

两期减法均精确勾稽，六列类别金额也与合计一致；2025 年末存货净额另与第 123 页合并资产负债表行一致。来源为第 193 页分类表“合计”行的表格坐标。`inventory_margin_pressure` 现在有完整输入并返回 `not_triggered`，不代表存货没有价格或减值风险。

## 回归与边界

这两种修复只处理**有文本层且表格列序明确**的年报。扫描财务表格、不同布局的多页附注仍需要独立识别和人工标注。单季现金流必须与全年现金流勾稽；存货表不满足列序、金额或类别合计时不能用别的列替代。`tests/test_column_order.py` 和 `tests/test_note_adapter.py` 有相应布局与拒绝异常表格的用例。原三份年报人工标注基准也已重新通过。

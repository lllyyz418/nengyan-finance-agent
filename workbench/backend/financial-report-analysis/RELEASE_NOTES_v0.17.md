# v0.17 交付说明

新增扫描候选确认到财务分析的衔接。`create_scan_review_template` 创建全待确认记录；`prepare_reviewed_scan` 校验文件哈希、候选快照、人员记录、公司/年度、合并范围、币种及重述状态；`analyze_reviewed_scan` 调用已有公式和风险规则。接口与本地命令行见 [SCAN_REVIEW.md](SCAN_REVIEW.md)。

支持确认、纠正、拒绝和待确认。修改金额或单位时保留 OCR 原值及具体来源；重复确认值冲突时整个指标的本期和上期均被拦截。金额输入只接收十进制字符串，换算和计算继续使用 `Decimal`，不以归母利润替代合并利润，也不补出缺失成本或季度金额。

核心增加可选的 `value_sources`、`value_units`（按期间索引），使扫描本期和上期分别引用对应金额单元格和单位。原适配器继续使用其行来源与单位。可选 `withheld_inputs` 传递未确认、拒绝、冲突原因到不可计算指标和风险规则；财务公式、风险条件和原入口返回版本均未改变。新入口包装版本为 `0.17`，嵌套年度分析仍沿用原合同。

复核数据中的 `kind="human"` 只是声明，调用代码不能鉴别实际操作人员。成员 1 应在后台控制身份、保存候选及复核记录，把真实人员的决定传入；模型不得自主确认。哈希用于绑定内容，不能证明源文件真实性。

本版没有扩展 OCR 的字段覆盖：仅确认已有五类摘要候选。因此大部分组合风险可能仍为 `insufficient_data`；不存在信号不能说明“无风险”。真实低清扫描件、手写材料与财务附注的识别验收仍待补充。

本版执行 104 项相关回归，全部通过，包括确认链边界、命令行文件保护、原三份年报集成与半年报核心期间规则。复用同次年报解析结果检查 135 个原始标注字段，全部通过；39 项独立公式复算也通过。三份已有模拟扫描的确认记录测试回放核对 20 个金额，全部匹配。回放模拟人类记录，仅验证算法路径，不构成新的人类确认。Skill 元数据与已验证的 v0.16 相同，新文档引用和 Python 源码语法检查通过。
